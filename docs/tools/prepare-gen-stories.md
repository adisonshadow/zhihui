

## 一、Form Card 交互控件（建议）

**基础所需：**
1. **创新度滑块 (Slider)**  
   - 标签：`常见套路` ——— `天马行空`
   - 默认值：中间值
   - 说明：控制生成内容的保守/离谱程度。

2. **题材 (Segment，单选)**  
   - 选项：`任意`、`玄幻仙侠`、`历史架空`、`现代都市`、`科幻末世`、`悬疑惊悚`、`无限流`、`游戏异界`、`末日废土`、`古风权谋`、`轻小说日常`

3. **受众倾向 (Segment，单选)**  
   - 选项：`任意`、`男生向`、`女生向`、`大众向`

**额外建议增加（帮你想的）：**

4. **情感 / CP 模式 (Segment)**  
   - 选项：`任意`、`无CP剧情向`、`纯爱1v1`、`大女主/大男主万人迷`、`多角恋纠葛`、`兄弟情/闺蜜情`  
   - 说明：漫剧观众对感情线敏感，提前确定走向。

5. **故事基调 (Segment)**  
   - 选项：`任意`、`轻松搞笑`、`热血王道`、`甜宠治愈`、`暗黑虐心`、`悬疑烧脑`、`正剧写实`

6. **节奏 & 篇幅 (可拆为两个，也可合并)**  
   - 节奏：`任意`、`快节奏爽文`、`慢热铺陈`、`张弛有度`
   - 篇幅：`任意`、`短篇（1-10话）`、`中篇（10-50话）`、`长篇连载（50+话）`

7. **灵感关键词（Input，选填）**  
   - 占位符：`例如：重生、系统、女扮男装、反派洗白……（空格分隔）`

## 二、提示词组织方式（重点）

当用户点 **「开始」** 后，根据表单数据拼接成以下形式的用户提示词，再发起 AI Chat（发送给故事生成模型）。

### 拼接规则
- 若选项为 “任意”，则不在提示词中做限制（或写“不设限”）。
- 把 Slider 值转化为自然语言：
  - 最左（0-20%）→ “请严格遵循经典商业叙事模板，角色定型化，情节可预测。”
  - 中间（20-80%）→ “在经典框架中加入适量创新元素，保留熟悉感的同时提供惊喜。”
  - 最右（80-100%）→ “请颠覆套路，大胆采用反常规设定、反转结构和非典型主角，脑洞优先。”

### 提示词模板（示例）

```
你是一位专业的漫剧/轻小说作家。请根据以下创作偏好，生成10个小说雏形。

【核心要求】
- 创新度：{根据滑块自动填入上面对应的描述}
- 题材：{题材选项}
- 受众：{受众选项}
- 情感模式：{CP模式}
- 故事基调：{基调}
- 叙事节奏：{节奏}
- 预期篇幅：{篇幅}
- 灵感关键词：{关键词，若无则写“无特定要求”}

【输出格式】（请严格按此结构返回）
1. 故事标题：（一个吸引人的标题）
2. 一句话卖点：（15字以内，突出核心冲突或爽点）
3. 世界观简述：（2-3句话交代背景和规则）
4. 主要角色：
   - 主角A：（名字、身份、性格、目标）
   - 重要配角B：（与主角的关系及作用）
   - 可选反派/助力：（简要）
5. 前三话剧情大纲：
   - 第1话：开篇钩子与初次冲突
   - 第2话：发展、矛盾升级或世界观展开
   - 第3话：小高潮或转折，留下悬念
```

### 示例填充效果

假设用户选择：  
- 创新度滑块：靠右 70%（“在经典框架中加入适量创新元素...”）  
- 题材：历史架空  
- 受众：女生向  
- CP模式：纯爱1v1  
- 基调：甜宠治愈  
- 节奏：张弛有度  
- 篇幅：中篇  
- 灵感关键词：重生 经商 王爷
