# 图片编辑器：矢量编辑模式 — 用户操作与预期效果

本文档描述**进入矢量编辑模式**后，用户操作、系统输入输出与**预期行为规则**，供产品审阅与实现对照。若与当前代码不一致，以本文档为准迭代产品或代码。

---

## 1. 术语

| 术语 | 含义 |
|------|------|
| **矢量图层** | 图层面板中的一条矢量图层（如 `EditorPathObject`），语义上相当于**一份 SVG 文档的整体**：带位置、尺寸、旋转等**整体变换**；用户在画布上将其作为「一个矢量对象」拖移、缩放。 |
| **path** | 与 **SVG `<path>`** 对应。产品语义：**每一个 path 表示一个封闭图形**（一笔闭合轮廓）。实现上可对应 `pathData`（`d`）里由 `M…Z`（或等价）分隔的一段轮廓，或与独立 `<path>` 元素一一对应。 |
| **复合路径** | 同一条 path 的 `d` 中含**多条闭合轮廓**，配合 **`fill-rule="evenodd"`**（或等价语义）表现**镂空、打孔**；视觉上是一块**带洞**的形状，而不是多个可各自填不同色的独立 path。 |
| **矢量元素层** | **不是图层面板里的图层**。进入矢量编辑后，编辑的是该矢量图层**内部的**矢量结构，可类比 SVG 里 **`g` + 若干 `path`**。当前**不支持用户自定义编组**，产品描述上可**直接视为其下多个 path 的集合**（不必向用户强调 `g`）。矢量元素层内的 path **仅在矢量编辑模式下**可编辑、删除；退出后随该矢量图层一起变换与导出。 |
| **主选择（图层选择）** | `selectedIds` 决定的图层面板/画布选中对象。进入矢量编辑前须选中**一个矢量图层**；编辑过程中**图层主选择**仍指向该矢量图层（变换框、检查器主体等），与**矢量元素层内选中了哪些 path** 是**两套互不相干**的选择状态。 |

**心智模型（帮助文案可摘）**：每个 path 是一块封闭形状；**带洞的字母**常用 **evenodd** 把外圈与内圈合成一条**复合路径**。

---

## 2. 总体原则

- 矢量编辑只修改**当前矢量图层**内部的**矢量元素层**；**不**把 path 当成图层面板里可新建的一层。
- 对 path 的填色、布尔、删除、平移等，**结果均写回该矢量图层**，**不因这些操作新增图层面板中的矢量图层**（与实现不一致时以本文为准收敛实现）。
- **变换框**作用于**整层**；path 级几何与样式在矢量编辑 UI 中完成。

---

## 3. 矢量渲染规则

### 3.1 层叠顺序

同一矢量图层内，多个 path 按结构顺序绘制（如 SVG 中顺序）；**后绘制的叠在先绘制的之上**。不同矢量图层之间按**图层面板顺序**叠放。

### 3.2 镂空与分色

- **复合路径**：多轮廓 + **`fill-rule="evenodd"`** → 打孔/镂空（定义见 §1 术语表）。
- **分色**：不同 path 可有不同填充与描边；未单独指定的 path 回落到**该矢量图层的默认样式**。

### 3.3 与位图编辑

位图模式编辑像素；矢量模式只动当前层内的 path / 复合路径，**不在图层面板新增矢量图层**。

---

## 4. 进入与退出矢量编辑模式

### 4.1 前置条件

- 选中**一个矢量图层**。
- 当前几何**可编辑**（`pathData` 含不支持的指令时应提示并禁止进入）。

### 4.2 进入后

用户在编辑**该层内部的矢量元素层**，而不是新建图层面板条目；整层变换与 path 编辑的分工见 §2。

### 4.3 退出

用户点击「完成矢量编辑」，或**主选择不再是当前正在编辑的矢量图层**时，退出矢量编辑会话（细则可与实现一致）。

---

## 5. path 的选择（矢量元素层内）

- **点选 path 内部**：选中该 path（显示锚点等编辑态）。
- **点选 path 外部**（未命中任一 path）：视同点到**画布 / workspace 空白**，**取消** path 选择（是否同时退出矢量模式由产品另定）。
- **Shift + 点选**：多选 / 取消（toggle）。
- **框选**：空白处拖矩形，与矩形**相交**的 path 入选。
- **Shift + 框选**：与当前选中集合**并集**。
- **锚点**：path 选中后可编辑锚点与手柄；**Shift + 点选锚点**多选，用于尖角/平滑、删锚点、加中点锚等。

**实现对照（非用户文案）**：内部可用 `activeSubpaths` 等下标表示「第几个封闭轮廓」，产品对外统一称 **path**。

---

## 6. 对选中 path 的操作

| 操作 | 输入 | 预期 |
|------|------|------|
| **填充 / 描边 / 线宽** | 一个或多个 path 已选，在检查器修改 | 仅选中 path 样式变化，**其余 path 不变且仍可见** |
| **布尔**（合并 / 打孔 / 相交 / 差集） | **恰好两个**封闭 path 已选 | 用新轮廓**替换**这两段几何，**仍在同一矢量图层**；其它 path 不变；打孔方向/顺序在 UI 中约定说明 |
| **删除** | 已选 path | 从当前矢量图层移除；若删至无 path，删层或保留空层由产品定稿 |
| **平移** | 在 path 面内拖拽 | 平移选中 path（可多条），其它 path 不变 |
| **简化路径** | 打开简化面板、拖动「曲线精度」 | 在**自然坐标**（与图层 `pathData` 一致）下：先沿原曲线**密集采样折线**，再 **RDP** 减点，最后用 **Catmull-Rom（张力 0.5）→ 三次贝塞尔**重建平滑锚点与手柄；目标接近 Illustrator「减锚点、用曲线保形」。 |

具体交互样例见 **§7 分镜示例**。

#### 6.1 简化路径（实现约定）

- **坐标**：采样、RDP、拟合全程在 **path 的局部自然坐标**（`naturalW×naturalH` 空间下的 `d`）中进行，与画布上矢量叠加层使用同一套数，**不做文档坐标变换**。
- **手柄存储**：`PathVertex.handleIn` / `handleOut` 与 `svgPathEditModel`、SVG `C` 指令一致，为**绝对控制点坐标**，不是相对锚点的偏移；拟合阶段须写绝对值，否则预览/填充会严重错位。
- **闭合轮廓 RDP**：采样折线首尾与起点重合时，**不能**对「首尾同一点」的开折线直接做标准 RDP（端点退化）；实现上在环上取弦分裂为两条开链再合并，避免整圈塌成两点。
- **开放路径**：端点单侧切线；内部点用相邻采样点的 Catmull-Rom 切线。
- **预览**：红色为选中子路径原始轮廓，半透明填充为**整层** `pathData` 的简化结果（未选子路径几何不变，仅选中项被替换）。

## 7. 分镜示例

**示例素材（转矢量后，进入矢量编辑可见矢量元素层）：**

- 白底位图上有 **A、B、C** 三字母（可不同色）；**A、B** 内部均有镂空（白底透出）。
- 结构上可包含：字母 **A、B、C** 各自外轮廓 path；**A** 的镂空区对应 **1 个**三角形 path；**B** 的镂空区对应 **2 个**圆角矩形 path（表示打过圆角的镂空区域）等（以实际转矢量结果为准）。

### 7.1 打孔

- **操作**：同时选中 **A 外轮廓 path** 与 **A 中间三角形** path，点击**打孔**。
- **叠放约定**：同一 `pathData` 内子路径顺序与 SVG 一致——**序号小者先绘制（在下层）**，**序号大者后绘制（在上层）**。打孔为 **下层减去上层**（用**上层**轮廓在**下层**上挖洞），与点选顺序无关；故应保证 **A 外轮廓**在路径数据中的序号**小于**三角形（外轮廓在下、镂空三角形在上），即可得到字母 **A** 的镂空效果。
- **中间未选 path**：两个选中子路径在代码顺序（`pathData` 序号）之间，**可能夹有其它未选中的子路径**；**打孔布尔只对当前选中的两条**做几何运算，**不把**这些中间的 path 参与计算；写回图层后，**中间的 path 仍保留在原位置**（序号区间不变、几何不变）。
- **预期**：得到**带镂空的字母 A**（宜为 **§1** 所述**复合路径** + **evenodd**）；**B、C 及 B 的镂空 path 均无变化**。

### 7.2 着色

- **操作**：同时选中 **A 中间三角形** path 与 **字母 C** path，填充设为绿色。
- **预期**：仅这两个 path 变为绿色，**其它 path 不变**。

---

## 8. 导出与外部查看

导出 SVG 时保留**分 path 的填色**；含镂空处须保留 **`fill-rule="evenodd"`**（或等价）以保证洞正确显示。

---

## 9. 暂不实现 / 范围外

- 用户将多个 path **自定义组合进 `g`** 并作为可编辑分组（多 `g` 编辑与持久化）。
- path **渐变填充**（线性、径向等）。

---

## 10. 实现与当前文档的对应关系

**已与 §2 对齐（当前实现）**

- 填色、描边、线宽、布尔等均在**同一矢量图层**（同一 `EditorPathObject`）内更新 **`pathData`** 与可选的 **`pathSubpathStyles`**，**不会**因此新增图层面板中的矢量图层。
- 矢量编辑模式下画布**仍显示**位图/形状/文字等其它图层；仅对当前编辑中的 path 图层施加 **vectorEditLock**（避免拖移整层干扰锚点编辑）。

**数据模型（实现细节）**

- 存储上仍为**单条 SVG `path` 的 `d`** 串联多段闭合轮廓，配合 **`pathSubpathStyles[i]`** 与轮廓下标对齐，与文档「每个 path 一个封闭图形」一一对应；导出时再拆为多 `<path>` 或保留复合 `d`，见导出逻辑。

**待验收 / 可选优化**

- [ ] 布尔与底层库（Paper.js）在自交、重叠等极端几何下的形态是否满足 §7.1 复合路径 + **evenodd** 的预期。
