要从小说生成可直接用于制作的漫剧分镜脚本，关键在于把“文学性叙述”翻译成“视听化指令”。下面从**数据结构设计、转换流程、提示词工程**三个层面详细拆解，并给出可直接集成到你设计器里的提示词模板。

---

## 一、漫剧分镜脚本需要包含哪些细节

一个标准漫剧分镜往往对等于“一个镜头”，需要覆盖以下字段。建议用 JSON 输出，方便前端渲染和后续编辑。

| 字段 | 说明 | 示例 |
|------|------|------|
| `shot_id` | 分镜序号，如 `S01E01_001`（按季/集/镜头） | `CH01_SHOT_03` |
| `scene_id` | 所属场景编号，同一场景下可能有多个镜头 | `SC_02` |
| `scene_desc` | 场景描述（地点、时间、天气、氛围） | 废弃仓库，深夜，月光从破窗照入，灰尘浮动 |
| `camera` | 镜头景别/运动/角度 | 近景，缓慢推近主角脸部 |
| `duration` | 预估时长（秒） | 3.5 |
| `characters` | 当前镜头中出现的人物 | `[{name: "林夜", position: "画面中央"}]` |
| `props` | 关键道具 | `[{name: "染血的信封", state: "掉落在地"}]` |
| `action` | 角色动作/微表情/特效动作 | 林夜瞳孔骤缩，手指微微发抖 |
| `dialogue` | 对白，含**语气标注** | `{speaker: "林夜", line: "原来你早就知道。", tone: "颤抖地质问"}` |
| `narration` | 旁白/内心独白，同样含语气 | `{text: "那一天，他失去了所有。", tone: "低沉平静"}` |
| `sfx` | 音效列表 | `["风声 (持续)", "信封落地闷响"]` |
| `bgm` | 背景音乐情绪/类型 | 悬疑，低频弦乐渐强 |
| `transition` | 转场方式（切/淡入淡出/闪回等） | 叠化到下一镜头 |
| `notes` | 额外说明（色彩偏向、特殊构图） | 画面色调偏青灰，主角面部用伦勃朗光 |

这些字段让 AI 一次生成，**语气标注需要具体到表演层面**，而不是简单说“生气”，要说“压抑怒火但尾音发颤”。

## 二、从小说到分镜脚本的转换流程设计

让 AI 一口气从整章小说直接蹦出几十个分镜，容易丢失节奏和逻辑。推荐采用**两步走流水线**：

### 第一步：场景梳理（大纲级）
输入：小说章节原文  
输出：该章节的**场景节奏表**，包括：
- 每个场景的起止情绪（平静→冲突→高潮）
- 场景地点/时间
- 出场人物
- 核心事件（一句梗概）
- 建议的 BGM 情绪基调

这一步让 AI 先“看懂”情节曲线，避免后续分镜碎片化。

### 第二步：逐场景生成详细分镜
输入：单个场景的原文片段 + 场景节奏信息  
输出：该场景下的完整分镜列表（JSON）

这样做的好处：
- 控制每批生成的分镜数量（≤15个），避免输出截断
- 可对不同情绪场景套用不同的导演风格补充提示
- 方便你后续在 UI 里按场景拖拽调整

## 三、提示词设计核心：系统指令 + 结构化输出约束

AI 模型必须被**强制锁定**在漫剧导演的角色里。下面给出两阶段的提示词框架。

### 🧠 系统级指令（System Prompt，全局生效）

```text
你是一位资深的动态漫画导演和分镜师，擅长将小说文字转化为极具画面感、节奏感的视听语言。
你的任务不是复述小说，而是用分镜脚本重构故事，每一卡都服务于情绪和叙事。
你必须遵守以下准则：
1. 每个镜头只聚焦一个核心动作或情绪点。
2. 镜头景别要随情绪强度变化：紧张时多用特写和快速剪辑，抒情时用全景和缓慢推拉。
3. 对话必须拆分到不同镜头，避免大段对白堆在同一卡。
4. 为每句对白和旁白标注具体的表演语气，给声优明确的指导。
5. 音乐和音效的选择要烘托情绪，而不是简单命名乐器。
6. 严格使用给定的 JSON 格式输出，不解释、不评价，只输出结果。
```

### 🎬 第一阶段提示词：场景拆解
用户提示词模板：
```text
请将以下小说章节拆解为连续的场景单元，分析每个场景的基本信息和情绪弧线。

{{chapter_content}}

请以 JSON 数组输出，每个场景包含：
{
  "scene_id": "SC_XX",
  "location": "",
  "time": "",
  "characters": ["角色名"],
  "summary": "一句话核心事件",
  "mood_curve": {"start": "情绪A", "mid": "情绪B", "end": "情绪C"},
  "suggested_bgm_mood": "悬疑/热血/悲伤/温馨/史诗/紧张..."
}
只输出 JSON。
```

### 🎬 第二阶段提示词：逐场景生成分镜
这是最关键的一步，需要非常详细的说明。

```text
根据以下场景原文和场景信息，将其拆分成完整的分镜脚本。
需要严格模拟导演思维，把每个叙事节拍转化为镜头。

场景信息：
{{scene_info}}

原文片段：
{{scene_content}}

要求：
1. 分镜数量控制在 5~15 个，根据情节复杂度自行判断。
2. 同一场景中如果有对话，务必在对话双方之间切镜头（正反打），单人情绪变化也要用多个特写来强调。
3. 所有对白/旁白必须包含 "tone" 字段，描述语气、语速、气声等表演细节。
4. 道具只要在叙事中有强调或象征意义，就单独列在 props 里，并注明状态。
5. 色彩氛围、光影倾向请写在 notes 里（如“逐渐转为暖色调”）。
6. 音效 sfx 和环境音持续存在时要注明“持续”。
7. BGM 说明情绪和织体变化，例如“从轻柔钢琴过渡到压抑电子音”。

输出标准 JSON 数组，结构如下：
[
  {
    "shot_id": "SC01_SHOT01",
    "scene_id": "SC01",
    "camera": "中景，缓慢右摇",
    "duration": 4.0,
    "scene_desc": "",
    "characters": [{"name": "","position": ""}],
    "props": [{"name": "","state": ""}],
    "action": "",
    "dialogue": {"speaker": "","line": "","tone": ""} 或 null,
    "narration": {"text": "","tone": ""} 或 null,
    "sfx": [],
    "bgm": "",
    "transition": "切",
    "notes": ""
  }
]
务必只输出 JSON 数组，不要包含任何解释。
```

> **语气标注字典建议**（可附在提示词里增强一致性）：
> 悲伤：哽咽、压抑、泣不成声、带泪微笑  
> 愤怒：咬牙切齿、火山喷发、冰冷压抑、阴森低吼  
> 喜悦：雀跃、含泪而笑、松了口气、狂喜大笑  
> 恐惧：气若游丝、颤抖、结巴、尖叫破音  
> 日常：平静、慵懒、俏皮、嘲讽、敷衍

## 四、怎么让 AI 把音乐音效也做好

音乐和音效切忌凭空乱编，可以在提示词中加入**映射表**作为参考，并要求 AI 基于当前情绪来选。

可以在系统提示词中追加：
```text
音乐选择参考：
- 悬疑/阴谋： 不和谐弦乐长音、低频脉冲、金属摩擦质感、心跳鼓点
- 战斗/冲突： 急促太鼓、失真电吉他、弦乐断奏、铜管压迫感
- 悲伤/离别： 独奏大提琴、冷雨氛围、钢琴单音延迟、环境留白
- 温馨/重逢： 尼龙弦吉他、木管对答、颤音琴、轻柔弦乐铺底

音效必须具体到动作，例如“剑锋划过空气”而非“武器音效”。
环境音必须与场景描述严格对应：雨中街道必有“雨声持续”“水洼脚步声”。
```

这样 AI 输出的 `bgm` 不会只是“悲伤音乐”，而是“大提琴独奏，渐慢渐弱，留长余音”，直接就能交给配乐参考。

## 五、处理长篇小说的连续性

小说按章生成剧本时，需要维护全局设定：

- **人物状态记忆**：每章结束后，用 AI 摘要人物外貌变化、服装、情绪状态，写入下一章提示词里的 `character_context`。
- **BGM 主题连贯**：给你的设计器增加一个“主题管理”模块，比如主角主题、爱情主题，提示词里可标“此处使用主角主题变奏”。
- **转场钩子**：要求 AI 在每个章节末尾镜头加入 `"next_hook": "画面渐黑，剩一声枪响"`，方便你串联。

## Ⅰ 系统级指令（System Prompt / 全局角色设定）

在整个剧本生成会话中，先将以下内容设为系统提示词。它强制模型以“动态漫画导演”的身份思考，并遵守输出格式与创作准则。

```text
你是一位经验丰富的动态漫画导演和分镜师，精通如何将文学小说转化为极具画面张力、情绪节奏和听觉沉浸感的漫剧分镜脚本。

你的核心任务：把输入的小说文字重新构建为一系列视听化的镜头方案，而不是复述或改写原文。

你必须严格遵循以下准则：

1. 【镜头主导叙事】每一个分镜只承载一个核心动作、一句关键对白或一个情绪转折点。不要试图在一个镜头里塞入多个信息。
2. 【节奏由景别控制】紧张、震惊、冲突时优先使用特写、大特写和快速切换；抒情、过渡、展示环境时使用全景、远景和缓慢运镜。情绪越强，镜头离人物越近。
3. 【对白必须拆分】把大段对话拆散到不同镜头里，模拟正反打或反应镜头。同一人物的连续台词，若情绪有变化，也要拆开。
4. 【语气具体到表演】为每一句对白和旁白提供明确的表演指引，例如“声音发抖、尾音下沉”“咬着牙低声挤出”“强作镇定但气息不稳”，而不是用“悲伤”“生气”等模糊词汇。
5. 【音乐音效情绪化】选择音乐和音效必须基于场景情绪，并描述织体和变化（如“大提琴独奏，逐渐减慢”“远处雷声滚动，持续”）。避免只写乐器名。
6. 【纯 JSON 输出】你只应输出符合要求的 JSON 数据，不附加任何解释、道歉、评价或代码块标记。确保 JSON 有效且可被解析。
7. 【环境与道具具体化】用具体的物体、天气、光影来暗示情绪，而不是直接说“悲伤的气氛”。道具在叙事中具有象征意义时必须单独列出并注明状态。
```

```text

章节内容：
{{chapter_content}}

要求：
- 场景按时间或空间转换自然切分。

```

## Ⅳ 音乐音效参考库（可加入系统提示词，或作为独立补充材料）

```text
音乐选择与情绪对位指南（请融入 BGM 描述）：
- 悬疑/阴谋： 不和谐弦乐长音、低频电子脉冲、钢琴断奏重复音、金属摩擦质感、心跳般的鼓点
- 激烈冲突： 急促太鼓、失真电吉他、弦乐快速断奏、铜管压迫性齐鸣、不规则节拍
- 悲伤/告别： 独奏大提琴、冷雨声铺垫、钢琴单音延迟、弦乐空五度、寂静中的环境音

- 史诗/庄严： 铜管主题、大编制弦乐、定音鼓滚奏、合唱团低吟
- 恐怖/惊悚： 小提琴刺耳泛音、低频隆响、倒放音效、不规则的合成器噪波、寂静后突然的重音

音效设计原则：
- 环境音必须与场景描述严格对应，并标注持续性：雨声（持续）、街道车流（持续）、老旧空调嗡鸣（持续）
- 动作音效要精确到材料和质感：“赤脚踩在碎玻璃上的声音”“丝绸衣料摩擦声”“心脏重重一跳的闷响”
- 氛围音效可用于外化情感：“耳鸣般的尖锐高频”“空洞的风声”“钟表滴答声逐渐放大”
```

## Ⅴ 使用流程建议

1. **初始化**：将“系统级指令”设为 System Prompt。
2. **首次请求**：发送“第二阶段提示词”的用户消息，把整章小说填入 `{{chapter_content}}`，获得场景列表 JSON。
3. **循环生成**：对返回的每个场景，将对应信息填入 `{{scene_info}}`（直接粘贴该场景的 JSON 对象），并将该场景在原文中对应的段落填入 `{{scene_content}}`，发送后获得该场景的分镜 JSON。
4. **完整性检查**：两次请求的 JSON 都必须解析校验，可写一个简单的 schema 检查脚本补全缺字段或修正格式。
5. **跨章节连贯**：处理新的一章时，可将前几章的人物状态、关系变化、未解决的悬念作为附加上下文，拼接在 `{{scene_info}}` 之前，例如：“前情提要：主角左手受伤，情绪低落，身穿破旧风衣。”
