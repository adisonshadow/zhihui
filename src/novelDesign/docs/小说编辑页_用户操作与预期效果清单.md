
## 整理后的需求清单

### 一、整集写作（核心流程）

| 触发条件 | 预期行为 |
|---|---|
| 用户说"写第N集""重写第N集""新增一集" | 1. 若集不存在 → 先调用 `novel_create_episode` 创建空集<br>2. 切换到目标集编辑区<br>3. 调用 `novel_get_episode` 读取大纲（若上下文不已有）<br>4. 调用 `novel_get_episode` 读取前一集正文（用于剧情承接）<br>5. 输出 `novel-body-json` 代码块写入正文 |
| 模型先输出解释文字再输出 novel-body-json | 编辑区在检测到 `novel_write_payload` 前不写入 |
| novel-body-json 之后模型继续输出总结 | 编辑区停止写入，后续只展示在对话区 |
| JSON缺失 `content_markdown` 或为空 | 自动触发一次JSON重试（每轮最多一次） |

### 二、输出格式规则

| 规则 | 说明 |
|---|---|
| **正文载体** | 必须在 assistant 回复中以 `novel-body-json` 代码块输出：`{"novel_write_payload":{"n":<集号>,"mode":"replace\|append","title":"<纯标题>","content_markdown":"<正文>"}}` |
| **禁止混入正文的内容** | 标题行、分隔线（如`---`）、完结标记（如"第N集·完"）、总结语（如"已完成/内容涵盖"）、条目化看点列表 |
| **标题规则** | `title` 只写纯标题（如"包子铺的最后一天"），禁止含序号前缀（如"1、"、"第一集"） |
| **聊天气泡行为** | novel-body-json 代码块不在对话区展示；只显示"撰写中"/"已完成"卡片；前期分析文字可展示；正文仅写入编辑区 |

### 三、局部修改

| 操作 | 工具 | 说明 |
|---|---|---|
| 替换指定文本 | `novel_replace_content` | 精确替换 |
| 删除指定文本 | `novel_delete_segment` | 精确删除 |
| 替换/删除失败 | — | 对话区给出失败原因，不改动正文 |

### 四、集管理结构操作

| 操作 | 工具 |
|---|---|
| 创建集 | `novel_create_episode` |
| 重命名集 | `novel_rename_episode`（禁止重命名大纲） |
| 删除单集 | `novel_delete_episode` |
| 删除范围 | `novel_delete_body_episode_range`（"第N集及之后"必须一次调用） |
| 打开/切换集 | `novel_open_body_episode` |
| 集排序 | `novel_reorder_episode` |
| 拆集 | `novel_split_episode` |
| 合集 | `novel_merge_episodes` |
| 列出所有集 | `novel_list_episodes` |
| 判集是否存在 | `novel_body_episode_exists` |
| 读故事大纲 | `novel_get_episode(__story_outline__)` |
| 更新大纲 | `novel_update_outline` |
| 改小说标题 | `novel_rename_novel` |

### 五、"新增一集"特殊规则

- 默认追加到最后一集之后
- **不要**先追问标题、插入位置或是否读大纲
- 自行根据大纲和上一集拟定纯标题
- 先 `novel_create_episode` → 再 JSON 正文

### 六、整集写作 vs 工具写入的分工

| 场景 | 使用路径 |
|---|---|
| 整集写作/重写/新增 | 第12条 JSON 格式（`novel_write_payload`） |
| 局部修改 | `novel_replace_content` / `novel_delete_segment` |
| 其他结构操作 | `novel_create_episode` 等工具 |

### 七、禁止事项汇总

- ❌ 禁止对故事大纲改名
- ❌ 禁止 JSON `content_markdown` 为空时强行覆盖正文
- ❌ 禁止在 `content_markdown` 中包含标题行、分隔线、完结标记、总结语
- ❌ 禁止对话区重复展示整段正文
- ❌ 禁止逐集调用 `novel_delete_episode` 代替范围删除
- ❌ 禁止打印 JSON 代码块到对话气泡
- ❌ 禁止用 `novel_write_body_episode` 做整集写作（用JSON）
